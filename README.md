# Go 算法练习

> AI 盛行的时代，古法手搓爱好者偶尔刷题记录下，编程语言不定期更换

每日一题的题解仓库，按日期组织，题目主要来自 [LeetCode](https://leetcode.cn/)。

## 目录结构

```
.
├── main.go          # 测试入口，调用当前题目的示例用例
├── 20261009.go      # 按日期命名的题解文件（2026年10月9日）
├── 20261010.go
├── ...
└── go.mod
```

## 题目列表

| 日期 | 函数 | 题目 | 思路 |
|------|------|------|------|
| 2026-10-09 | `minInsertions` | 平衡括号字符串的最少插入次数 | 贪心，统计未匹配左括号数 |
| 2026-10-10 | `sumOfSquares` | 特殊元素的平方和 | 遍历，判断下标是否为长度因子 |
| 2026-10-11 | `minSumSquareDiff` | 数组最小相等差值的平方和 | 排序 + 贪心分配操作次数 |
| 2026-10-13 | `maxAlternatingSum` | 重新排列后的最大交替和 | 绝对值排序，大数取正、小数取负 |
| 2026-10-14 | `maxSumOfSquares` | 数位和等于指定值的最大数字 | 贪心，优先填 9 |
| 2026-10-15 | `sumCounts` | 子数组不同元素数目的平方和 | 枚举子数组 + 哈希集合去重 |
| 2026-10-17 | `minSwaps` | 按数位和排序的最小交换次数 | 置换环，环大小 k 需 k-1 次交换 |

## 使用方式

```bash
# 运行 main.go 中的示例用例
go run main.go 20261015.go

# 编译检查
go build ./...

# 格式化
gofmt -w .
```

## 新增题解的约定

1. 新建以当天日期命名的文件，如 `20261020.go`，包名为 `main`
2. 函数名与题目函数签名保持一致
3. 在 `main.go` 中调用新函数，用题目示例做验证
4. 提交前执行 `gofmt -w .` 保证格式统一
